COMMUNITY RULES

📢 Qajeelfama Groupii

Seerota KEYRADDIIN MEDIA hordofuu qabdan.

📌 Seensa

KEYRADDIIN MEDIA bakka barnoota, beekumsaa, oduu fi odeeffannoo faayidaa qabu qooduuf qophaa'eedha. Miseensi hundi qajeelfama kana kabajuu qaba.

✅ 1. Waan Maxxansuun Eeyyamamu

  • Oduu sirrii fi amanamaa.
  • Barnoota, notes fi kitaabota barnootaa.
  • Gaaffii fi deebii barnootaa.
  • Saayinsii, seenaa fi herrega.
  • Teknoolojii fi odeeffannoo ICT.
  • Beekumsa waliigalaa.
  • Odeeffannoo hawaasaaf faayidaa qabu.
  • Yaada barnootaa fi marii kabajaan geggeeffamu.
  • Beeksisa admin irraa eeyyama argate.

❌ 2. Waan Maxxansuun Hin Eeyyamamne

  • Suuraa dhuunfaa fi viidiyoo faayidaa hin qabne.
  • Qabiyyee bashannanaa groupii kanaan wal hin qabanne.
  • Jokes, memes fi stickers walitti fufiinsaan erguu.
  • Chat dhuunfaa fi haasawa jaalalaa.
  • Beeksisa daldalaa eeyyama malee maxxansuu.
  • Referral links fi links affeerraa nama sassaaban.
  • Oduu hin mirkanoofne ykn sobaa ta'e.
  • Spam fi ergaa irra deddeebi'anii erguu.
  • Arrabsoo, doorsisa fi walitti bu'iinsa uumuu.
  • Qabiyyee seera qabeessummaa fi kabaja namaa cabsu.

📋 3. Dirqama Miseensotaa

  • Admin fi miseensota biroo kabajuu.
  • Oduu maxxansuu dura madda isaa mirkaneessuu.
  • Gaaffii barnootaa yeroo gaafattan ifatti barreessuu.
  • Ergaa nama biraa irratti yaada kabajaan kennuu.
  • Qajeelfama kana yeroo hunda hordofuu.

⚖️ 4. Tarkaanfii Admin

Namni qajeelfama cabsu haala yakka isaa irratti hundaa'uun tarkaanfii armaan gadii irratti ni mudata:

  • ⚠️ Akeekkachiisa kennuu.
  • 🗑️ Ergaa seera cabsu haquu.
  • 🔒 Maxxansuu yeroo murtaa'eef daangessuu.
  • 🚫 Yeroo barbaachisaa ta'etti group keessaa baasuu.

🤝 Wal Kabajaa, Wal Gargaarraa!

Kaayyoon keenya beekumsa qooduu fi hawaasa fayyaduudha. Kanaaf miseensi hundi gahee isaa haa bahatu.
